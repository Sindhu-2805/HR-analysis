# HR Analysis Dashboard

Developed an interactive **HR Analysis Dashboard using Power BI** to analyze employee workforce data and provide insights into employee trends.

### Key Features

* Analyzed active employees, employee separations, and new hires.
* Compared employee data by **gender, age group, region, and job type**.
* Analyzed average employee tenure by region and gender.
* Created interactive filters for **Region and Year**.
* Used Power BI visualizations to identify workforce patterns and support HR decision-making.

### Tools Used

**Power BI | Excel | Power Query | DAX**

### Dashboard Insights

The dashboard provides insights into active employees, new hires, separations, age-group distribution, job types, and regional workforce trends.
